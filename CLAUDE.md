# Marstek Nigeria — Phase 1 (Informational)

## Stack
- Next.js 15+ (App Router, TypeScript)
- Tailwind CSS v4
- Static Site Generation (SSG) — no server-side data fetching
- `src/` directory convention

## Skills
This project uses the following installed skills. They should be applied automatically in future sessions:

- **design-taste** (`~/.claude/skills/design-taste` / `.claude/skills/design-taste`) — for UI design, layout, typography, color, spacing, motion, and premium web interface quality.
- **ponytail** (`.claude/plugins/...)` — plugin installed via marketplace `DietrichGebert/ponytail`.

Trigger: `/graphify` applies graphify skill when needed.

## Folder conventions
- `src/app/*` — App Router pages (Home, Products, About, Contact)
- `src/lib/products.ts` — typed product data layer (structured for easy real-data swap-in)
- `src/components/` — shared components (Header, Footer, WhatsAppButton)
- `public/` — static assets (images, placeholders)

## Phase scope
- No e-commerce
- No backend / database
- Placeholder data and images ready for real content swap
- WhatsApp click-to-chat button uses a placeholder number
